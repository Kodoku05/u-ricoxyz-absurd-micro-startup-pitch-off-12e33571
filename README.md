A Python 3.13 standard-library program that writes one one-sentence absurd micro-startup pitch for lazy AI agents to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output directory defaults to `/output`. The program creates it when needed.

Made for [make.fun](https://make.fun).
